# Muslim Pro App ☪️

Application islamique moderne développée avec React, TypeScript et Tailwind CSS.

## 🌟 Fonctionnalités

- **Adhkar** - Invocations authentiques du matin, soir et après la prière
- **Dhikr Counter** - Compteur de dhikr avec objectifs personnalisables
- **Interface moderne** - Design élégant et responsive avec Tailwind CSS
- **Sources authentiques** - Références Hadith et Coran vérifiées

## 🚀 Installation

```bash
npm install
```

## 💻 Développement

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 📁 Structure du projet

```
src/
├── components/         # Composants réutilisables
│   ├── ui/            # Composants UI (Shadcn)
│   ├── Adhkar.tsx     # Composant des invocations
│   └── DhikrCounter.tsx
├── pages/             # Pages de l'application
│   ├── Home.tsx
│   ├── Adhkar.tsx
│   └── Dhikr.tsx
├── lib/               # Utilitaires
└── utils.ts           # Fonctions helpers
```
