# 🚀 ÉTAPES RAPIDES - MAP 1v1 FORTNITE

## ⚡ VERSION EXPRESS (15-20 MINUTES)

### 1️⃣ IMPORTER LES SCRIPTS (2 min)
- Ouvrir UEFN
- Panneau Verse > Créer dossier `Scripts`
- Copier `game_manager.verse` et `shop_system.verse`
- Cliquer sur **Compile**

### 2️⃣ PLACER LES SPAWNS (3 min)
- Ajouter 10-15 **Player Spawner** sur la map
- Bien les espacer partout

### 3️⃣ GAME MANAGER (5 min)
- Glisser le device **game_manager** sur la map
- Dans ses propriétés :
  - **SpawnPads** : Sélectionner tous les Player Spawner
  - **ItemGranters** : Créer 5 Item Granter avec des armes différentes et les sélectionner

### 4️⃣ SHOP (5 min)
- Créer **5 boutons** dans une zone
- Créer **3 Item Granter** (armes shop)
- Créer **2 Mutator Zones** (Double Jump + Speed Boost)
- Glisser le device **shop_system** sur la map
- Connecter TOUS les boutons et devices au Shop System

### 5️⃣ CONFIGURER L'ÎLE (2 min)
- My Island > Settings
- Max Players : **10-16**
- Respawn : **2 seconds**

### 6️⃣ TESTER (3 min)
- Launch Session
- Tester les kills → pièces
- Tester le shop
- Tester le spawn aléatoire
