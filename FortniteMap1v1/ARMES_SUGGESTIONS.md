## 📝 COMMENT TROUVER CES ARMES DANS UEFN

1. Dans UEFN, ouvrez un **Item Granter**
2. Cliquez sur **"Item to Grant"**
3. Dans la barre de recherche :
   - Tapez **"Mythic"** pour voir les armes mythiques
   - Tapez **"Exotic"** pour voir les armes exotiques
   - Tapez le **nom de l'arme** directement

4. **Filtres utiles** :
   - Rarity : **Mythic** ou **Exotic**
   - Type : **Weapon**

## 💡 CONSEILS

1. **Testez les armes** avant de finaliser votre choix
2. **Variez les types** : 1 AR, 1 Shotgun, 1 Sniper par exemple
3. **Armes fun** > Armes méta (les joueurs veulent s'amuser !)
4. **Regardez des vidéos** sur YouTube : "Fortnite mythic weapons" pour voir les effets

## ✅ CE QU'ON CHERCHE

✅ **Effets uniques** (explosions, feu, repousse, etc.)
✅ **Dégâts élevés** (pour que ça vaille le coup d'acheter)
✅ **Visuels cool** (particules, effets, sons)
✅ **Armes rares** qu'on ne voit pas souvent
✅ **Fun à utiliser** (sinon personne n'achète)
