# 🎮 MAP FORTNITE 1v1 REALISTIC - SYSTÈME COMPLET

## 📋 RÉSUMÉ DU SYSTÈME

### ✅ SPAWN AUTOMATIQUE
À chaque spawn/respawn, vous recevez **5 ARMES** (variantes aléatoires) :
1. **Fusil d'Assaut** (Common/Uncommon/Rare)
2. **Pompe** (Common/Uncommon/Rare)
3. **PM** (Common/Uncommon/Rare)
4. **Soin** (Bandages/Med Kit/Shield)
5. **Objet d'Échappement** (Shockwave/Grappler/Launch Pad)

### 💰 SHOP
Gagnez **1 pièce par kill** et achetez :
- **Armes Mythiques/Exotiques** (5, 7, 10 pièces)
- **Pouvoirs** : Double Jump (8p) + Speed Boost (6p)
